## 三、思考問題回答

**問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？**
* **回答**：
  * **以 3 人計算的原因**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，其中 `"amy"` 重複報名了兩次。根據規則，同一個人在同一場活動只算一位參加者並只收費一次，因此實際參加人數為 3 人。
  * **轉成 `list` 與 `set` 的差異**：將字串用 `split(",")` 拆成 `list` 時，**保留了**原始報名的先後順序與重複出現的次數（可看出誰重複報名），但**失去了**直接進行數學集合運算（交集、差集）的便利性；將 `list` 轉成 `set` 後，**保留了**不重複的參加者名單與快速比對能力，但**失去了**原本的報名順序與重複次數資訊。

**問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**
* **回答**：
  * **集合關係說明**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$。兩者的**聯集（$A \cup B$）**元素個數為 3（代表總不重複人數為 3 人）；兩者的**交集（$A \cap B$）**元素個數也為 3，代表這 3 位同學同時參加了兩場活動。
  * **算式說明**：
    * **報名人次**為兩場各自去重人數相加：$|A| + |B| = 3 + 3 = 6$ 人次。
    * **總應收**為兩場分別計費相加：$(3 \times 120) + (3 \times 80) = 360 + 240 = 600$ 元。
